# PROJECT_MAP — anymodel

**How to use this map:** read the entry for a file before editing it. Each entry lists the file's purpose, key exports/signatures, which other project files it depends on, and non-obvious notes. This map was regenerated after the ES-module refactor (2026-08-19). If it goes stale after structural changes (new/renamed/moved files or functions), update only the affected entries then, not the whole map.

**App:** zero-backend, bring-your-own-key AI chat app. Vanilla JS, no build step, no dependencies. All application code lives under `src/` as ES modules wired together by `src/main.js` (the single `<script type="module">` in `index.html`). Classes receive a `deps` object via constructor injection — no `window.*` globals. Data persists in `localStorage` under `anymodel_*` keys. Run with `python3 -m http.server 8899`.

### ./src/main.js (entry point)
- **Purpose:** Boot/entry: theme init (no-flash, `anymodel_theme_v1`), frame-busting guard, theme toggle, dependency injection, async app init.
- **Exports:** none (side-effect module). Exposes `window.__robotAvatar`, `window.__state` for debug only.
- **Internal deps:** all config, utils, services, state, components (see load order below).
- **Notes:** `init()`: `state.initKeys()` → `catalog.ensureLoaded()` → `api.fetchModels()` → fallback model pick → render all → `chat.initHero()` → suggestion grid → `intentRouter.load()` (async, non-blocking). One shared `deps` object is passed to every component; circular refs (settings↔header↔sidebar↔composer↔chat) are resolved by mutating `deps` after construction.

## Cross-cutting notes (read before editing)

- **Load order (module graph):** `main.js` → config (constants → capabilities → demo-tools) → utils (dom → icons → markdown → toasts) → services (catalog → storage → api → intent) → state → components. Components are constructed by `main.js` and receive one shared `deps` object; circular refs are patched onto `deps` after construction.
- **Dependency injection:** Components destructure what they need from `this.deps` at method-call time (`const { $, state, icon } = this.deps;`). `$` is always `byId` (document.getElementById). Never declare `const $` twice in one method scope.
- **State shape:** messages `{role, content, modelUsed?, toolUsed?, isError?, imageDataUrl?, audioDataUrl?, audioDurationMs?, tokenEstimate?}`; sessions `{id, title, provider, createdAt, updatedAt, messages[]}`; active session mirrored in `state.messages`.
- **Capabilities drive endpoints** (`config.getEndpointType`): chat / transcription / tts / ocr / embeddings / moderation. Adding an endpoint touches capabilities.js (cap label → `CAP_META`), catalog (normalizeModel, pickModel), api (endpoints.js), composer (branch), header (placeholder).
- **Keys are encrypted** in `localStorage` (AES-256; passphrase stays in memory) and **never leave the browser** — respect keylock/appState key-handling invariants.
- **Intent router** auto-switches models (tts/image intents) for one turn and restores afterwards; training `train_model.py` and `src/services/intent/router.js` share the same `SELF_TESTS` — keep in sync when retraining.
