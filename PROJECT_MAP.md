# PROJECT_MAP — anymodel

**How to use this map:** read the entry for a file before editing it. Each entry lists the file's purpose, key exports/signatures, which other project files it depends on, and non-obvious notes. This map was generated once by an agent run and may go stale after structural changes (new/renamed/moved files or functions); update only the affected entries then, not the whole map.

**App:** zero-backend, bring-your-own-key AI chat app. Vanilla JS, no build step, no dependencies. All files are classic scripts sharing globals via `window.*` namespaces (except `js/intent-router.js`, an ES module). Script load order matters and is fixed at the bottom of `index.html`. Data persists in `localStorage` under `anymodel_*` keys. Run with `python3 -m http.server 8899`.

### ./fasttext.js (523)
- **Purpose:** Official fastText WebAssembly wrapper (Facebook, MIT); loads the Emscripten runtime module and exposes a `FastText` class for model loading/prediction.
- **Exports:** `FastText` (class: `loadModel(url)`, `predict(...)`), `addOnPostRun(fn)`.
- **Internal deps:** `import fastTextModularized from './fasttext_wasm.js'`.

### ./train_model.py (90)

## Cross-cutting notes (read before editing)

- **Load order:** `icons → config → catalog → state → markdown → api → components/* → intent-router (module) → app`. Components call each other through `window.*`; never re-declare `const $`/`const icon`.
- **State shape:** messages `{role, content, modelUsed?, toolUsed?, isError?, imageDataUrl?, audioDataUrl?, audioDurationMs?, tokenEstimate?}`; sessions `{id, title, provider, createdAt, updatedAt, messages[]}`; active session mirrored in `State.messages`.
- **Capabilities drive endpoints** (`Config.getEndpointType`): chat / transcription / tts / ocr / embeddings / moderation. Adding an endpoint touches config (cap label → `CAP_META`), catalog (`normalizeModel`, `pickModel`), api (`call*`), composer (branch), header (placeholder).
- **Keys are encrypted** in `localStorage` (AES-256; passphrase stays in memory) and **never leave the browser** — respect `state.js` key-handling invariants.
- **Intent router** auto-switches models (tts/image intents) for one turn and restores afterwards; training `train_model.py` and `intent-router.js` share the same `SELF_TESTS` — keep in sync when retraining.
